# 앨범·웹 위젯 헤더 정리

## 목표

- 앨범 위젯은 평소 사진을 가득 보여주고, 위젯에 마우스를 올리거나 헤더 액션에 키보드 포커스가 들어오면 헤더를 사진 위에 표시한다.
- 앨범 설정에서 헤더를 `호버 시 표시` 또는 `항상 표시`로 고를 수 있다.
- 웹(iframe) 위젯의 별도 주소 행을 제거하고 URL과 브라우저 열기 액션을 공통 위젯 헤더에 합친다.

## 설계

`WidgetShell`에 기존 정적 헤더와 앨범 전용 호버 오버레이 헤더 모드를 둔다. 오버레이 모드는 레이아웃 높이를 차지하지 않고 `group-hover`와 `group-focus-within`에서 보인다. 앨범 설정값이 없는 기존 보드와 새 위젯은 요청한 동작을 바로 얻도록 호버 모드를 기본으로 해석한다.

웹 위젯은 설정 URL을 헤더 제목으로 사용한다. 기존 본문 주소 행의 `브라우저에서 열기` 동작은 공통 헤더의 위젯 전용 액션 슬롯으로 옮긴다. 알려진 임베드 차단 안내 안의 복구 버튼은 그대로 유지한다.

## 검증

- `WidgetShell`의 정적/호버 오버레이 모드와 키보드 공개 클래스를 단위 테스트한다.
- 앨범 기본 설정과 설정 폼 변경을 테스트한다.
- 웹 위젯 본문에 중복 주소 행이 없고, 호스트 헤더에 URL과 외부 열기 액션이 있는지 테스트한다.
- 전체 프론트 테스트, 타입 검사, 린트, 빌드를 실행한다.
